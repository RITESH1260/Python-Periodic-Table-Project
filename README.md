# 🧪 Interactive Periodic Table using Python

A professional and interactive **Periodic Table Project** developed using **Python, Pandas, NumPy, and Jupyter Notebook**.  
This project demonstrates scientific data organization, table manipulation, and visualization techniques in Python.

---

## 🚀 Features

- Periodic Table Structure upto 20
- Organized Element Data
- Atomic Number Representation
- Mass Number & Symbol Display
- DataFrame Manipulation using Pandas
- NumPy Integration
- Clean Jupyter Notebook Interface
- Beginner Friendly Project

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook
